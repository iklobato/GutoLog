# Quickstart: Freight Quote Engine

## Prerequisites
- Python 3.11+
- `uv` installed

## Setup
1. Create a virtual environment:
   - `uv venv`
2. Install dependencies:
   - `uv pip install -r requirements.txt`

## Run
- Use the engine via the Freight Budget Management UI or integrate with a service endpoint.

## Validate
- Provide a valid request with known tables and verify each component in the breakdown.
- Submit invalid requests (exceed insurance limit, overweight vehicle) and verify errors.
